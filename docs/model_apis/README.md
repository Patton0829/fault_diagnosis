# 本地接口配置资料

原始接口资料只保留在本机，不提交 API Key、个人资料或内网部署地址。
公开仓库仅保存脱敏的 `*.example.md`，它们不是已验证服务的凭证或建库回执。

新环境可将 `本地Embedding模型调用.example.md` 复制为同目录的
`本地Embedding模型调用.md`，再填写自己的 Ollama 地址，并独立验证维度与模型。
真实配置文件在 Git 中被忽略。不要替换当前已有指南：现有缓存和 Milvus 清单绑定了
原指南、模型 digest 和输入规则的指纹；更换配置应准备新的缓存和索引，不能修改旧清单绕过验证。

云端千问演示通过环境变量或本机 `models/.env` 配置 `DASHSCOPE_API_KEY`；
模型名通过对应脚本的 `--model` 选项选择，以该脚本支持的选项为准。
不要把密钥写进 Python 示例或提交记录。
