## TEST-SW-001 转辙机动作超时

故障现象：
转辙机收到转换命令后开始动作，但在规定时间内未到达目标位置，监控系统提示“动作超时”。

可能原因：
1. 滑床板或尖轨区域存在异物，导致机械阻力增大。
2. 表示杆、动作杆安装偏斜或润滑不足。
3. 电源电压偏低，电机输出转矩不足。
4. 电机、减速器或摩擦联结器状态异常。

排查步骤：
1. 做好现场安全防护，确认设备已停止动作。
2. 检查尖轨、基本轨和滑床板区域是否存在异物、积雪或严重锈蚀。
3. 检查动作杆和表示杆是否弯曲、卡阻或连接松动。
4. 测量动作期间的输入电压和三相电流，比较各相数据是否均衡。
5. 空载试验正常但带载超时时，应重点检查机械阻力和密贴调整。

处置建议：
清除异物并恢复润滑；紧固或调整连接部件；电压或电流异常时继续检查供电回路与电机。未经确认不得连续反复操纵设备。

## TEST-SW-002 转辙机三相电流不平衡

故障现象：
电流A、电流B、电流C之间差异明显，其中一相持续偏高或偏低，设备动作伴随异常振动。

判断参考：
同一动作阶段内，任意两相电流差异超过正常基线的20%，可初步判定为三相电流不平衡。

可能原因：
1. 电源缺相、接线端子接触不良或电缆阻抗异常。
2. 电机绕组局部短路或绝缘性能下降。
3. 采集传感器安装方向错误或量程配置不一致。

排查步骤：
1. 核对电流传感器的安装方向、编号和量程。
2. 检查电源端子、电缆接头及保护器件是否松动或过热。
3. 在停电条件下测量电机各相绕组电阻并比较差异。
4. 使用独立仪表复测三相电流，排除采集系统误差。

处置建议：
先排除传感器配置问题，再处理供电回路或电机故障。发现缺相时应立即停止设备运行。

## TEST-SW-003 加速度A突增但电流正常

故障现象：
加速度A出现连续尖峰，加速度B和加速度C变化较小，同时三相电流处于正常范围。

可能原因：
1. A轴加速度传感器固定螺栓松动。
2. 传感器安装面存在间隙或安装方向发生变化。
3. 传感器线缆受碰撞，产生瞬态干扰。
4. 局部机械部件松动，但尚未明显增加电机负载。

排查步骤：
1. 检查A轴传感器底座、固定螺栓和安装方向。
2. 检查线缆屏蔽、接头以及走线固定情况。
3. 对比同一动作周期的三轴波形，确认尖峰是否只出现在A轴。
4. 重新紧固后执行低风险测试动作，观察尖峰是否消失。

处置建议：
优先检查传感器安装和信号线路，不应仅根据单轴尖峰直接判定电机故障。

## TEST-SW-004 表示到位但密贴不良

故障现象：
控制系统显示转辙机已到位，但现场检查发现尖轨与基本轨之间存在异常缝隙。

可能原因：
1. 表示杆调整不当，电气表示与机械位置不一致。
2. 密贴调整量不符合要求。
3. 尖轨根部、滑床板或连接部件存在机械卡阻。
4. 检测机构触点提前接通。

排查步骤：
1. 禁止仅依据远程到位信号判定设备安全。
2. 现场检查实际密贴状态和锁闭状态。
3. 检查表示杆、动作杆及检测机构的调整位置。
4. 检查触点动作顺序，确认表示信号不会提前形成。

处置建议：
重新调整机械密贴与表示机构，并完成现场联锁验证后方可恢复使用。

## TEST-SW-005 激光测距数据固定不变

故障现象：
设备多次动作后，激光测距值始终保持同一数值，而电流和转速数据正常变化。

可能原因：
1. 激光测距传感器被遮挡或镜面污染。
2. 通信链路中断，系统持续显示最后一次有效值。
3. 采集程序字段映射错误。
4. 传感器进入保持或冻结状态。

排查步骤：
1. 清洁传感器窗口，检查测量路径是否被遮挡。
2. 查看原始报文中的时间戳是否持续更新。
3. 对比数据库最新记录与设备实时输出。
4. 核对字段映射是否为 laserDistance，单位是否为 mm。

处置建议：
若时间戳也停止变化，应优先检查通信与采集进程；若时间戳更新但数值固定，应检查传感器及字段映射。

## TEST-SW-006 电机转速正常但丝杆转速为零

故障现象：
电机转速有正常读数，丝杆转速持续为零，设备无法完成转换。

可能原因：
1. 电机与传动机构之间的联轴器松脱。
2. 减速器或传动齿轮损坏。
3. 丝杆转速传感器失效或接线中断。

排查步骤：
1. 停机并隔离电源后检查联轴器和传动部件。
2. 手动检查传动链是否存在空转或卡死。
3. 使用独立测速手段确认丝杆是否实际旋转。
4. 若丝杆实际旋转但系统显示为零，检查转速传感器和采集通道。

处置建议：
实际不旋转时处理机械传动故障；实际旋转但无数据时处理传感器或采集链路故障。

## TEST-SW-008 安全处置通用要求

当出现冒烟、焦糊味、异常高温、持续过流或明显机械破损时，应立即停止操纵并隔离电源，设置现场防护，禁止带故障反复试验。检修完成后，应依次进行静态检查、空载试验、带载试验和状态确认，并保存检修记录。
